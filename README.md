# pedroluzdecastro.com

Canonical source files for Pedro Luz de Castro's academic website and CV.

- Website pages and assets live in the repository root.
- The editable CV source is [`cv/CV.tex`](cv/CV.tex).
- Run `./cv/build.sh` from any directory to rebuild the public
  `Pedro_Luz_de_Castro_CV.pdf` in the repository root.

The repository is published through GitHub Pages at pedroluzdecastro.com.
